Porting 36 Python String Distance Algorithms to 100% Safe, Zero-Dependency Rust.

Port Mortem Hackathon — Track D Submission

The Python Baseline

Original Library: life4/textdistance

  • 30+ mathematically complex algorithms
  • Uses heavy C-extensions (`rapidfuzz`) to survive
  • Relies on `numpy` for DP matrices
  • Fails when external libraries break

The Port Mortem Challenge

  • Maintain 100% behavioral parity
  • Eliminate all C-extensions & dependencies
  • Zero `unsafe` blocks
  • Make it blazingly fast natively

The Rust Architecture

  • Traits over Classes: Clean `TextDistance` and `TextSimilarity` trait bounds replacing Python's messy inheritance.
  • Zero Dependencies: Native `Vec>` replaces numpy. Native byte tracking replaces C-extensions.
  • Rayon Parallelization: The API executes all 36 algorithms simultaneously across all CPU cores.
  • Differential Fuzzing: Built a custom fuzzer to assert mathematical parity against the Python original to the `1e-6` precision.

The SaaS Dashboard (WASM)

To prove the portability of Rust, we didn't just build a library.

  • Compiled the entire library to WebAssembly (WASM)
  • Built a premium React + Vite dashboard
  • Result: Users can compute 36 algorithms instantly, directly in their browser. Zero server latency. Zero backend costs.
